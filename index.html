01 research

Efficient models, fast systems, and AI that builds both.

Model capability keeps scaling, and so does the cost of running it. Long contexts make attention memory-bound. Diffusion and video models need several GPUs per request. Every new model family arrives with its own serving problem. I want to close the gap between what a model should cost and what it actually costs in production.

I work on this at three levels. First, the model: architectures and attention mechanisms that are efficient by design. Second, the system: conventional ML-systems work that turns those savings into wall-clock speed. Third, and increasingly, the engineer. A few experts still hand-tune each new stack, so I study whether coding agents can do that work themselves. An agent runs on the same systems it optimizes, so every gain makes the agent better too. That is recursive self-improvement.

the model machine learning systems

  1. 01 efficient model architecture

    Compute less, by design

    Model and attention designs that skip work the model never needed. That covers sparse attention for long-context and block-diffusion decoding, and redundancy-aware parallel decoding for diffusion language models.

    RISA · R²-dLLM · Vortex

  2. 02 conventional ml systems

    Make it fast on real GPUs

    Classic systems work: serving engines, sequence parallelism, SLO-aware GPU scheduling and efficient inference pipelines for LLMs and diffusion models. Everything is built and measured on real clusters, from H200s down to PCIe-connected commodity GPUs.

    Vortex · GenServe · SparSP · QRMark

  3. 03 recursive self-improvement

    Let agents build the system

    Agents that do systems work themselves: build LLM serving engines from scratch, compress models under a storage budget, write new sparse-attention algorithms. I build the programmable substrates and benchmarks that make this possible and measurable.

    ServerBench · CompressionBench · Vortex

// on measuring agents

A speedup an agent claims is only as trustworthy as the evaluator that measured it. My RSI benchmarks use frozen tasks, offline sandboxes, fixed deadlines and a hidden verifier the agent never sees, so the final number means what it says.

02 papers

Publications & preprints

  1. submitted toICLR 2027

    RISA: Recoverable Sparse Attention for Block-Diffusion Language Models

    Xinrui Zhong, Fanjiang Ye, Yuke Wang

    Block diffusion LMs re-read a growing KV cache at every denoising step. RISA sorts newly generated history into exact priority and recovery tiers, and lets seed queries build a single bounded read plan that every step of the block reuses. On DreamReasoner-8B this gives 2.32× faster sparse attention at a 32K prefix, rising to 5.53× at 128K.

  2. NeurIPS 2026

    Vortex: Efficient and Programmable Sparse Attention Serving for AI Agents

    Zhuoming Chen, Xinrui Zhong, Qilong Feng, Ranajoy Sadhukhan, Yang Zhou, Michael Qizhe Shieh, Zhihao Jia, Beidi Chen

    A Python-embedded DSL (vFlow) over a page-centric tensor abstraction (vTensor) expresses dynamic KV-cache routing over paged and ragged layouts, and runs inside production serving backends. New sparse-attention algorithms, including ones written by agents, go from idea to benchmark in minutes. With workload-aware planning, operator fusion and radix top-k selection, the best reach up to 3.46× the throughput of full attention with accuracy preserved.

    arXiv ↗ code ↗ website ↗

  3. submitted toNAACL 2027

    ServerBench: How can your coding agents design specialized LLM serving systems?

    Xinrui Zhong, Zhiming Wang, Yongqi Liu, Zhaohui Wang, Shanglin Yang, Zikun Li, Zhuoming Chen, Beidi Chen

    Agents start from a minimal server and build a complete, specialized LLM serving system, graded by stateful session replay and independent correctness checks. Across 11 agent models and three deployments, scored by latency-qualified token value per GPU dollar, one agent-built system reached 4.87× the vLLM reference on Gemma E4B.

    arXiv ↗ code ↗ blog ↗

  4. submitted toMLSys 2027

    CompressionBench: How can your coding agents compress LLMs?

    Xinrui Zhong, Zhifeng Li, Zhiming Wang, Yongqi Liu, Shanglin Yang, Yang Zhou, Zikun Li, Zhuoming Chen, Beidi Chen

    Each task gives a coding agent a pinned BF16 checkpoint, a storage budget and a deadline. The agent may use any mix of quantization, pruning, low-rank factorization and distillation. Once the deadline passes, a hidden evaluator checks package size, GPU memory and fidelity a single time.

    arXiv ↗ code ↗ blog ↗

  5. submitted toEuroSys 2027

    SparSP: Exploiting Communication Sparsity for Sequence-Parallel Video DiTs

    Desen Sun, Xinrui Zhong, Yuke Wang, Sihang Liu

    Video diffusion transformers are expensive enough to need multiple GPUs, but sequence parallelism stalls on bandwidth-limited PCIe links. SparSP exploits the sparsity in that communication so inference scales on commodity GPU servers.

    arXiv ↗

  6. submitted toNAACL 2027

    R²-dLLM: Accelerating Diffusion Large Language Models via Spatio-Temporal Redundancy Reduction

    Zhenbang Du, Kejing Xia, Xinrui Zhong, Yonggan Fu, Nicolai Oswald, Binfei Ji, Brucek Khailany, Pavlo Molchanov, Yingyan (Celine) Lin

    Diffusion LLMs predict tokens in parallel but still decode slowly. R²-dLLM removes redundant computation both within a denoising step (across tokens) and between steps.

    arXiv ↗ code ↗

  7. submitted toMLSys 2027

    GENSERVE: Efficient Co-Serving of Heterogeneous Diffusion Model Workloads

    Fanjiang Ye, Zhangke Li, Xinrui Zhong, Ethan Ma, Russell Chen, Kaijian Wang, Jingwei Zuo, Desen Sun, Ye Cao, Triston Cao, Myungjin Lee, Arvind Krishnamurthy, Yuke Wang

    An SLO-aware system that co-serves text-to-image and text-to-video diffusion requests on shared GPUs. Patch packing, spatial partitioning, preemption and elastic sequence parallelism let it adapt GPU allocation as the workload shifts.

    arXiv ↗

  8. submitted toMLSys 2027

    An Efficient and Adaptive Watermark Detection System with Tile-based Error Correction

    Xinrui Zhong, Xinze Feng, Jingwei Zuo, Fanjiang Ye, Yi Mu, Junfeng Guo, Heng Huang, Myungjin Lee, Yuke Wang

    QRMark makes detecting watermarks across large collections of generated images fast. Tile-based detection with Reed–Solomon error correction exploits redundancy across tiles to balance efficiency, scalability and robustness. It is up to 2.42× faster than existing baselines on Stable Signature and AquaLoRA.

Vortex

★ ·

Infini-AI-Lab / vortex_torch · co-developer

Programmable sparse attention for agents as algorithm designers. A PyTorch-like frontend runs on an SGLang backend with FlashInfer, CUDA Graphs and radix attention. It ships an agent workspace that writes, benchmarks and refines new sparse-attention algorithms end to end.

ServerBench

★ ·

Infini-AI-Lab / Server-Bench · lead developer

A harness where agents evolve a minimal server into a specialized LLM serving system. Tasks are frozen, containers are offline, Harbor composes the environment, and real agentic sessions are replayed against what the agent built. SGLang is measured as a reference and never copied in.

CompressionBench

★ ·

Infini-AI-Lab / Compression-Bench · lead developer

An autonomous model-compression benchmark on Qwen and Gemma checkpoints, with storage budgets from 8 to 32 GiB. Agents compress inside an offline container with a public checker. A hidden verifier judges the submission once, after the wall clock runs out.
